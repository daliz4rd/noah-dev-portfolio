# Noah — Developer Portfolio

Personal portfolio site featuring development projects and earlier design case studies.

**Live site:** https://daliz4rd.github.io/noah-dev-portfolio/

## Built with

- HTML, CSS, JavaScript
- jQuery, GSAP and ScrollMagic (from the original template)
- Canvas API and Web Audio API (Polyrhythms project)
- Hosted on GitHub Pages

## Run locally

No build step. From the project folder, start any static server, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
