Hover Helper

Point at any piece of code to learn what it is.

Description

A tool for new programmers: paste in some JavaScript, hover over any piece of it, and get a plain-English explanation of what that piece is called and what it's doing on that line.

  • The problem

    When I was starting out, a line like const re = new RegExp("ab+c"); was a wall of symbols. Syntax highlighting was supposed to help, but it wasn't always available, and when it was I still had to remember what each color meant. What I really wanted was to point at a piece of code and have something tell me what it was called and what it was doing.

  • The approach

    Hover Helper parses the code into a syntax tree and explains every token based on where it sits, so the same word gets a different explanation depending on its role. name might be a parameter, a variable being declared, a property, or a shorthand object key. Even brackets are explained: a parenthesis knows whether it opens a function call, a parameter list, or an if condition. Uses of a variable point back to where it was declared ("declared on line 1 with const"), and the tool flags common beginner mistakes such as reassigning a const or using a variable that was never declared. Every explanation links to MDN for further reading, and when the code has a syntax error it shows where and still explains the pieces it can.
